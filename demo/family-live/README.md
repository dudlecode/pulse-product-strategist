# Живой прогон: связь для близких и собственных устройств

Этот кейс агент собрал с нуля по брифу партнёра в чистой папке, без доступа к `demo/family-connect`. Оператор вымышленный, числа брифа учебные; всё, чего в брифе нет, записано как допущение или неизвестное.

## Что произошло

1. **Запрос и исследование, 9 минут.** Агент получил вопрос руководителя и PDF брифа, завёл журнал источников, посчитал сценарии скриптом, провёл три модельных интервью и остановился на развилке с пятью вариантами.
2. **Выбор человека и стратегия, 2,5 минуты.** Руководитель выбрал вариант B1; агент записал одобрение и написал итоговый документ из пяти частей брифа.
3. **Продолжение после перерыва, 3,5 минуты.** В новом чате без истории переписки агент восстановил состояние из файлов. Аналитик принёс новые сведения о причинах перебоев; агент оценил источник, нашёл затронутые выводы и запросил пересмотр.

Сообщения руководителя и аналитика заданы сценарием демонстрации и помечены в файлах как демонстрационный ввод.

## Файлы

- [sources/brief.pdf](sources/brief.pdf) — исходный материал: бриф партнёра.
- [brief.md](brief.md) — постановка задачи.
- [ledger.md](ledger.md) — источники, действия, расходы, неизвестные.
- [decision.md](decision.md) — варианты с сильными возражениями, рекомендация, запись о выборе.
- [strategy.md](strategy.md) — итоговый документ: продуктовая и коммуникационная стратегии, прогноз, план по кварталам, ресурсы и риски.
- [interviews/synthesis.md](interviews/synthesis.md) — три модельных интервью; только гипотезы.
- [updates/2026-11-22-01-support-causes.md](updates/2026-11-22-01-support-causes.md) — пересмотр после новых сведений.
- `calc/` — входы и отчёты расчётов; `state.json` — статус, обязательства, допущения, условия пересмотра.

## Проверить

Из корня репозитория:

```bash
python3 scripts/pulse.py validate demo/family-live
python3 scripts/pulse.py status demo/family-live
python3 scripts/pulse.py paid-months demo/family-live/calc/paid-months-input.json
```

## Границы

- Проверка оппонентом в этом прогоне не проводилась; она есть в соседнем кейсе `demo/family-connect`.
- Новые сведения аналитика — учебный ввод, а не данные оператора.
- Числа прогнозов немного отличаются от `demo/family-connect`: допущения агент назначал независимо. Выводы, которые от допущений не зависят, совпали.

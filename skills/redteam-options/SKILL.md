# Проверка оппонентом

Автор черновика склонен защищать свой вывод. Поэтому проверку делает исполнитель без истории чата: он видит только файлы кейса.

## Шаги

1. Убедись, что `decision.md`, `ledger.md` и расчёты сохранены: оппонент читает файлы, а не чат.
2. Запусти оппонента:
   - Claude Code — субагент `redteam` из `.claude/agents/redteam.md`;
   - другая среда — новый чат с текстом из того же файла и путём к папке кейса.
3. Оппонент только читает. Правки вносит основной агент.
4. По каждому замечанию реши: принять, отклонить с причиной или записать как неизвестное. Молча не отбрасывай.
5. Запиши результат в `updates/<дата>-redteam.md`: замечание, решение, что изменено, до и после. Обнови `ledger.md` и `state.json`.
6. Запусти `python scripts/pulse.py validate <папка>`.

## Критерий готовности

Каждое замечание имеет решение, изменения видны в `updates/`, проверка проходит.

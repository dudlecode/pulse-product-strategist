# Пульс — агент продуктовых решений

**От размытого запроса к решению, которое можно проверить и пересмотреть.** Пульс — папка с инструкциями, знаниями, навыками и одним скриптом. Её открывают в Cursor, Codex, Claude Code, Kimi Code или другой AI IDE, и модель из этой среды работает по правилам из папки.

Пульс не выдаёт уверенный текст за исследование. Он разделяет факты, гипотезы и прогнозы, показывает пробелы и стоимость, сравнивает «оставить как есть», «изменить» и «закрыть», сохраняет основания решения и условия пересмотра.

## Быстрый старт

1. Откройте папку в AI IDE.
2. Напишите агенту: **«Помоги решить: [вопрос]. Вот материалы: [файлы или ссылки]. Цель: [результат]»**. Правила агент возьмёт из `AGENTS.md`.
3. Если агент не начал работу сам, вставьте в чат текст из `prompts/START.md`.
4. Чтобы продолжить после перерыва или в новом чате, вставьте `prompts/RESUME.md`.

Локальные команды работают без ключей и пакетов, нужен только Python 3.10+:

```bash
python3 scripts/pulse.py demo
```

В Windows вместо `python3` пишите `python`. Модель, браузер и поиск даёт выбранная среда; их стоимость зависит от вашего тарифа. Конфиденциальные данные в папку не кладите.

## Демонстрационный проект

Задача руководителя цифрового продукта по брифу партнёра «Связь для близких и собственных устройств»: кому помочь первым, что изменить и стоит ли выделять людей и деньги. Агент прошёл бриф дважды, независимо.

### Живой прогон — `demo/family-live`

Сквозной путь в трёх частях: запрос и исследование, выбор человека и стратегия, продолжение в новом чате с пересмотром по новым сведениям.

- [strategy.md](demo/family-live/strategy.md) — итоговый документ с продуктовой и коммуникационной стратегиями.
- [decision.md](demo/family-live/decision.md) — варианты, возражения, запись о выборе.
- [updates/](demo/family-live/updates/2026-11-22-01-support-causes.md) — пересмотр после новых сведений.
- [README.md](demo/family-live/README.md) — что произошло и как проверить.

### Прогон с проверкой оппонентом — `demo/family-connect`

Тот же бриф, более ранний прогон. Черновик решения проверил независимый оппонент; после его десяти замечаний рекомендация стала осторожнее.

- [strategy.md](demo/family-connect/strategy.md) и [decision.md](demo/family-connect/decision.md) — также в PDF рядом.
- [ledger.md](demo/family-connect/ledger.md) — источники, действия, расходы, неизвестные.
- [interviews/](demo/family-connect/interviews/synthesis.md) — три модельных интервью и синтез гипотез.
- [updates/](demo/family-connect/updates/2026-11-22-redteam.md) — что изменилось после проверки оппонентом.

Воспроизвести расчёты и проверить оба кейса:

```bash
python3 scripts/pulse.py paid-months demo/family-connect/economics/paid_months.json
python3 scripts/pulse.py sample-size --p1 0.12 --p2 0.09 --weeks 6
python3 scripts/pulse.py validate demo/family-connect
python3 scripts/pulse.py validate demo/family-live
python3 scripts/pulse.py status demo/family-live
```

### Открытые страницы и скриншот — `demo/case`

Онлайн-подключение eSIM: страницы МегаФона и МТС, скриншот первого экрана заказа, синтетические таблица и экономика. Показывает разбор сайтов и интерфейса, пересмотр при новых данных и поиск просроченных обязательств. Команды — в [demo/case/README.md](demo/case/README.md).

## Что умеет

- Уточняет только те вводные, которые меняют следующий шаг.
- Строит план исследования от вопросов, способных изменить решение; ведёт журнал действий, источников, ошибок и расходов.
- Работает с документами, таблицами, сайтами и скриншотами; у каждого существенного сведения есть ссылка на источник.
- Считает воспроизводимо: проверка CSV, сценарная экономика, вклад оплаченных месяцев, объём пилота.
- Сравнивает не меньше трёх содержательно разных вариантов с сильными возражениями.
- Связывает продуктовую и коммуникационную стратегии и план проверки.
- Проводит модельные интервью для поиска гипотез и не выдаёт их за спрос.
- Отдаёт черновик решения независимому оппоненту без истории чата.
- Сохраняет статус одобрения, обязательства, допущения и условия пересмотра; `status` показывает просрочку.

## Ключевые решения

| Решение | Зачем | Чем заплатили |
|---|---|---|
| Папка с файлами, а не программа | Открывается в любой AI IDE, переносится копированием | Качество зависит от модели и инструментов среды |
| Состояние в файлах кейса: `brief.md`, `ledger.md`, `decision.md`, `state.json`, `updates/` | Работа продолжается в новом чате и в другой среде | Агент обязан обновлять файлы на каждом шаге |
| Инструкции, знания, навыки, материалы и состояние лежат раздельно | Прежний ответ агента не превращается в правило или факт | Больше файлов |
| Арифметика и проверки — в скрипте на стандартной библиотеке | Числа можно пересчитать без модели и без ключей | Скрипт умеет только заявленные расчёты |
| У каждого утверждения — ID и источник; `validate` ловит битые ссылки | Вывод можно проследить до основания | Журнал нужно вести дисциплинированно |
| Модельные интервью — на дешёвой модели, тремя независимыми прогонами | Гипотезы стоят секунды, прогоны не влияют друг на друга | Ответы ненадёжны в деталях и помечены как синтетические |
| Оппонент — отдельный исполнитель без истории чата | Автор черновика склонен защищать свой вывод | Ещё один вызов модели |
| Хуков и MCP нет | Не нашли задачи, где они окупают настройку в каждой среде | Проверку `validate` агент запускает сам по инструкции |

## Команды

| Команда | Что делает |
|---|---|
| `init <папка>` | Создаёт каркас нового кейса из шаблонов; существующие файлы не трогает |
| `validate <папка>` | Проверяет обязательные файлы, ссылки, источники, ID и состояние |
| `status <папка>` | Показывает фазу, следующий шаг, обязательства, просрочку, допущения, условия пересмотра |
| `analyze <csv>` | Описательная разница средних двух групп с проверкой ключа, диапазона и пропусков |
| `economics <json>` | Сценарная экономика: чувствительность, безубыточность, окупаемость |
| `paid-months <json>` | Вклад в прибыль через дополнительные оплаченные месяцы; граница цели |
| `sample-size` | Число единиц на вариант для сравнения двух долей и нужный поток в неделю |
| `demo` | Печатает сценарий демонстрации |

Параметры — `python3 scripts/pulse.py <команда> --help`.

## Новый кейс

```bash
python3 scripts/pulse.py init projects/my-question
```

Заполните `brief.md`, положите материалы в `sources/` и попросите агента начать.

## Структура

```text
AGENTS.md                 постоянные правила агента
CLAUDE.md                 вход для Claude Code, ссылается на AGENTS.md
knowledge/                методика: процесс, доказательства, интервью, маршрутизация
skills/                   повторяемые процедуры: интервью, оппонент, план пилота
.claude/agents/           субагент-оппонент для Claude Code
prompts/                  старт и продолжение
templates/                шаблоны кейса
scripts/pulse.py          локальные проверки и расчёты
demo/family-live/         кейс по брифу партнёра: живой прогон
demo/family-connect/      тот же бриф: прогон с проверкой оппонентом
demo/case/                кейс eSIM на открытых страницах
evaluation/               замеры и их ограничения
docs/                     описание работы (Markdown и PDF)
projects/                 ваши кейсы
```

## Стоимость и границы

- Локальные команды бесплатны и не вызывают сеть.
- Расход модели зависит от среды и тарифа. Агент записывает в `ledger.md` модель, причину выбора и расход каждого шага; если расход не измерен, так и пишет.
- Замеры по демонстрационному проекту — в [evaluation/results.md](evaluation/results.md).
- Агент не отправляет сообщения, не проводит реальные интервью без согласия и не принимает решение за владельца.
- Реальные интервью в демо не проводились. Все числа кейсов по брифу — учебные или допущения.

Приёмка и отрицательные сценарии — в [EVALUATION.md](EVALUATION.md).
